# 알약찾기

휴대폰에서 약학정보원 낱알식별 검색을 쉽게 쓰도록 **검색 조건 입력만 도와주는 가벼운 웹앱**입니다.
약 데이터를 따로 내려받지 않고, 고른 조건으로 약학정보원 검색을 대신 열어 줍니다.

## 기능

- 큰 버튼으로 모양·색·제형·분할선 선택
- 각인 글자는 영문·숫자 전용 키패드로 입력 (한/영 전환 없음), 앞↔뒤 바꾸기 버튼
- 고른 조건을 한 줄로 확인하고 "약학정보원에서 검색"
- 약학정보원에 다녀와도 조건이 30분 동안 남아 있음
- 설치 없이 링크로 열고, 홈 화면에 추가하면 앱처럼 사용

## 동작 방식

"약학정보원에서 검색"을 누르면 고른 조건이 담긴 약학정보원 낱알식별 검색 결과가 새 탭으로 열립니다.
약학정보원 검색 폼과 같은 이름·값을 주소에 담아 보냅니다 (`docs/index.html`의 `kpicUrl`).

## 동료와 같이 쓰기 (GitHub Pages, 무료, 선택)

1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: `claude/medicine-search-mobile-app-9zp97x`, 폴더: `/docs` → **Save**
3. 1~2분 뒤 https://bhw650-sys.github.io/Drug/ 에서 열림
4. 휴대폰 브라우저 메뉴에서 **홈 화면에 추가**

## 파일

- `docs/index.html`: 앱 전체 (화면, 스타일, 동작)
- `docs/manifest.webmanifest`, `docs/icons/`: 홈 화면 아이콘 설정

## 주의

검색 결과는 약학정보원(health.kr)이 제공합니다. 이 앱은 입력만 돕는 도구이며, 투약 전 최종 확인은 처방 내역과 함께 해야 합니다.
