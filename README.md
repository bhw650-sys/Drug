# 알약찾기(가칭)

간호사가 근무 중 휴대폰으로 알약을 빠르게 찾는 **낱알식별 검색 앱** 프로젝트입니다.

- **조건 검색**: 모양·색·각인·제형·분할선을 큰 버튼과 전용 키패드로 입력하고, 누를 때마다 남은 후보 수를 보여줍니다.
- **카메라 검색**: 사진에서 각인·색·모양을 읽어 검색 조건을 자동으로 채웁니다. 최종 확인은 후보 사진과 비교해서 합니다.
- **오프라인**: 식약처 낱알식별 공공데이터를 휴대폰에 받아 두고 통신 없이 검색합니다.
- **상세 정보**: 약학정보원과 의약품안전나라로 연결합니다.

## 문서

- [제안서](docs/PROPOSAL.md): 데이터 소스, 구조, 기술 스택, 입력 설계, 카메라 설계, 로드맵, 비용
- [화면 시안](docs/prototype/index.html): 가상 데이터로 눌러보는 시안 (파일을 내려받아 브라우저로 열기)

## 상태

기획(제안) 단계입니다. 진행 순서는 [제안서 8장 로드맵](docs/PROPOSAL.md#8-단계별-로드맵-개발자-1명-기준-대략)을 따릅니다.

## 주의

이 앱의 결과는 참고용입니다. 투약 전 최종 확인은 처방 내역과 약제부 확인으로 해야 합니다.
