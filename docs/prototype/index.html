알약찾기 화면 시안

바쁜 근무 중에도 한 손으로 알약을 찾을 수 있게 설계한 검색 화면입니다. 목록의 약은 모두 지어낸 예시이며 실제 의약품이 아닙니다.

이렇게 눌러 보세요

  1. 모양·색 칩을 누를 때마다 아래 버튼의 후보 수가 바로 바뀝니다. 처음에는 예시로 원형·하양이 선택되어 있습니다.
  2. 각인 칸을 누르면 영문 대문자·숫자 전용 키패드가 뜹니다. 한/영 전환 없이 입력하고, 앞·뒤 어느 면의 글자든 찾습니다.
  3. 조건을 너무 많이 골라 결과가 0개가 되면 어떤 조건을 빼면 되는지 알려줍니다.
  4. 카메라를 누르고 촬영하면 사진에서 읽은 조건이 노란 칸으로 채워집니다. 틀린 칸만 고치면 됩니다.
  5. 결과에서 약을 누르면 앞·뒤 모양, 크기, 분할선을 크게 비교할 수 있습니다.

시안에서 흉내만 낸 부분

  • 카메라 인식 결과는 예시 사진마다 미리 정해 둔 값입니다. 실제 앱은 휴대폰 안 글자 인식과 색·모양 분석을 하고, 필요하면 서버 AI 분석을 씁니다.
  • 약 그림은 모양 정보를 그린 것입니다. 실제 앱은 식약처 낱알식별 데이터의 제품 사진을 보여줍니다.
  • 약학정보원·의약품안전나라 버튼은 연결하지 않습니다.
